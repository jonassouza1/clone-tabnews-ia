# AGENTS.md

## Visão geral

Este repositório é um clone do TabNews, construído com Next.js e React para reproduzir a experiência de uma comunidade de compartilhamento de links e notícias.

## Objetivo do projeto

- Implementar uma aplicação inspirada no TabNews;
- focar em simplicidade, usabilidade e fluxo de publicação de conteúdos;
- servir como base de aprendizado para desenvolvimento web com Next.js.

## Stack principal

- Next.js
- React
- JavaScript / Node.js

## Diretrizes para agentes

- Priorize mudanças simples, legíveis e alinhadas às convenções do Next.js;
- mantenha o foco no objetivo do projeto e evite adicionar complexidade desnecessária;
- preserve a natureza didática e minimalista da aplicação;
- prefira documentação e nomes claros, especialmente em código novo ou modificado.
